# Fashion category images

Place the Fashion category images in this folder using these exact filenames:

- `dresses.jpg`
- `tops.jpg`
- `bottoms.jpg`
- `kente-prints.jpg`
- `traditional-wear.jpg`
- `accessories.jpg`
- `bags.jpg`
- `footwear.jpg`
- `others.jpg`

Recommended: square or near-square images, ideally 1000 x 1000 px or larger. The storefront crops these images into circles using `object-fit: cover`.
