# Fashion category hero media

This folder is reserved for locally stored category hero slideshow images.

Planned structure:

- `dresses/`
- `tops/`
- `bottoms/`
- `kente-prints/`
- `traditional-wear/`
- `accessories/`
- `bags/`
- `footwear/`
- `others/`

Each category folder will contain only the images used by that category's hero slideshow.

The future download script will be run manually once when we intentionally add or refresh assets. It will not run during `npm run dev`, `npm run build`, deployment, or normal website visits.
