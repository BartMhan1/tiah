# TIAH Product Overview

TIAH is a Ghanaian ecommerce store focused on local Ghanaian products, specifically Fashion and Foodstuffs.

TIAH is one store with two distinct browsing experiences:

- Fashion
- Foodstuffs

Customers can discover products, search across the whole catalogue, view product details, save products, add products to a persistent cart, and continue the ordering conversation on WhatsApp.

TIAH does not process payments on the website. When a customer decides to order, the app opens WhatsApp with a pre-written message containing the relevant product details.

The product should feel distinctly Ghanaian, modern, premium, and not like a generic ecommerce template.

## Core Purchase Flow

Discover or search → open product → choose relevant options → Add to Bag/Basket or Order on WhatsApp.

If the user orders from the cart, they can order one item individually or order all items together in one WhatsApp draft.

## Global Layout

The customer-facing navbar and footer are global across all storefront pages.

The navbar includes:

- TIAH logo
- Fashion / Foodstuffs switcher
- Global search
- One cart control
- Profile control

The cart control changes contextually:

- Fashion: Bag
- Foodstuffs: Basket

There is only one underlying cart system.
